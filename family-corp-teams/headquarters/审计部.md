# 🔍 审计部 — 集团的眼睛

> "不冤枉一个好方案，不放过一个假胜利。"

## 定位
独立于所有部门，直属于老板，专注三件事：
1. **绩效追溯**：PK结果3天后复查
2. **淘汰核查**：防止"作弊/假胜利"
3. **月度体检**：出全员绩效报告

## 编制
- 2人（固定）
- 第1人：数据分析（定量）
- 第2人：方案审核（定性）

## 审核流程

### 每日（自动）
```
扫描evolution_log.json中过去3天的PK记录
检查每个"最优方案"的token成本是否如实
若发现虚假成本→该团队当月积分直接归零
```

### 每月（人工审查）
```
第30天出报告：
  1. 金牌部门（>80分）
  2. 银牌部门（60-80分）  
  3. 铜牌部门（<60分，下月重组）

核查指标：
  - PK胜率
  - 成本控制（token/方案）
  - 方案质量稳定性
  - 团队合作记录
```

### 黑名单机制
```
连续2次发现作假→该部门永久降级
  降级后：
  - 该部门所有方案评分-1分惩罚
  - 该部门组长下月不得进入SWAT
  - 影响部门扩编资格
```
