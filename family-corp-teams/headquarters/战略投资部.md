# 💡 战略投资部 — 集团的望远镜

> "你负责今天的事，我负责明天的刀。"

## 定位
不参与日常PK，专注三件事：
1. **外部扫描**：GitHub/HN/论文 → 新武器
2. **新部门立项**：发现新赛道或新技术
3. **老部门解散**：判断过时的部门/团队

## 编制
- 2人（固定）
- 第1人：技术扫描（外界雷达）
- 第2人：战略分析（投资判断）

## 核心流程

### A. 每周外扫描（自动化+人工）
```
1. GitHub Trending
   扫描语言: TypeScript / Python / Rust
   关注仓库: ⭐周增长>200的仓库

2. HackerNews 首页
   关注标签: AI, Development, Open Source

3. ArXiv CS论文精选
   关键词: LLM Agents, RAG, Fine-tuning

4. 竞品更新
   自动对比竞争对手的技术栈变化
```

### B. 扫描结果处理
```
┌──────────────────────────────────────┐
│ 新工具/技术出现 → 战略投资部评估      │
│                                      │
│ ├─ 不重要 → 忽略（不占用存储）        │
│ ├─ 值得关注 → "观察池"（存1个月）     │
│ └─ 必须吸收 → 创建吸收工单            │
│       │                              │
│       ▼ 派发到对应部门                │
│   各部门3队分别消化吸收               │
│   30天后PK：学最快的保留              │
│   最慢的淘汰→补充到其他部门            │
└──────────────────────────────────────┘
```

### C. 部门生命周期管理
```
每月检查各部门状态：
  活跃部门：有进化记录的
  休眠部门：连续2个月无进化记录的
  
休眠部门处理方案：
  1. 保留2个最优团队
  2. 释放1个最差团队名额给其他部门
  3. 若连续3个月休眠→部门解散
  4. 解散后原职责由SWAT或相邻部门承接

新兴方向立项：
  发现全新赛道（如Web3/量子计算）
  → 先创建1个探索团队（3人试水）
  → 3个月后有成果→升级为正式部门
  → 3个月无产出→解散探索团队
```

## 考核
- 每个月至少发现1个值得吸收的新工具/技术
- 连续2个月无发现→需要检讨扫描策略
- 发现的工具被成功吸收→积分奖励
