# IGP 国际集团金字塔 —— 自我进化·自我净化·永不养闲人

## 🏛️ 总纲

> 公司不是家，是战场。能打仗的活，不能打的滚。
> 不进则退，不新鲜就腐烂，不迭代就淘汰。

### 核心原则

| 原则 | 含义 |
|------|------|
| **零闲人** | 每个团队每轮PK必须证明自己存在价值，没有"历史功臣" |
| **自我净化** | 输了不骂，但淘汰；淘汰后原编制自动解散，新生团队补位 |
| **自我吸收** | 外部GitHub/竞品/论文→消化→化为己用，不花钱的事情优先做 |
| **三层博弈** | 同部门3队盲盒PK + 部门间资源争夺 + 集团战略再分配 |
| **三天回溯** | 任何问题最多3天出方案，方案质量+token成本综合评分 |

## 🗡️ 参谋部 — 集团顶级战力（3个常设特种部门）

### 1. SWAT突击队（3人）
- **任务**：紧急事件/重大故障/跨部门难题
- **权限**：可调用任何部门资源
- **活水**：表现最好的个人进入SWAT，SWAT老人下放带团队
- **考核**：每次任务≤24小时，超时自动查问

### 2. 审计部（2人）
- **任务**：绩效追溯、淘汰核查、防止"假胜利"
- **规则**：得奖的团队3天后回查，代码/文档质量不达标→撤销奖项
- **黑名单**：连续2次作假→部门永久降级

### 3. 战略投资部（2人）
- **任务**：
  - 扫描GitHub Trending + HackerNews + 论文 → 新工具/新技术
  - 决定"哪个团队该转型"、"哪个部门该拆分/合并"
  - 新部门立项、老部门解散的最终决策

## ♻️ 进化机制（如何自我净化+自我吸收）

### 周期1：发现问题（看门狗，持续运行）
```
系统监控 → 日志异常/性能下降/用户投诉
人工触发 → 老板一句话/新需求/战略转向
外部吸收 → GitHub新项目/竞品新特性 → 自动创建工单
```

### 周期2：盲盒PK（每次工单触发）
```
工单 → 派发到对应部门3个团队（互不知情）
        ├─ 队1: 主流方案（成熟稳定）
        ├─ 队2: 替代方案（轻量/国产/免费）
        └─ 队3: 创新方案（最快/最新/最有风险）
        
各队独立出方案（3天或10秒虚拟加速）
```

### 周期3：三天回溯（评分淘汰）
```
评分 = 质量分(1-10) - token成本/500

┌──────────────────────────────────────┐
│ 胜者(最优方案) → 入最佳实践库           │
│ 败者(最差方案) → 入淘汰名单+通知队长     │
│ 中间者 → 自行反思+改进空间               │
└──────────────────────────────────────┘
```

### 周期4：淘汰与再生（自我净化核心）

**淘汰规则（0容忍）：**
| 条件 | 惩罚 |
|------|------|
| 一次PK垫底 | 黄牌警告 |
| 连续2次垫底 | **团队解散**，成员各奔东西 |
| 3个月无胜场 | 部门审查，考虑合并到其他部门 |
| 接到任务3天无方案 | 自动判定为输 |

**再生规则：**
```
团队解散后：
1. 原部门保留2个最优团队（剩下的队重组）
2. 从skills-local人才池中抽人重组成新队
3. 战略投资部决定用哪个新工具栈
4. 新队有1个月"新手保护期"（输了不清算）

每月第一天：
  战略投资部检查所有部门
  若某部门连续2个月无进化记录 → 该部门降为"休眠部门"
  休眠部门可被其他部门收购/合并
```

## 💰 不养闲人机制（全员经营责任制）

### KPI 自动结算（每个团队独立核算）

```
每个团队每月基础分 = 100分

加分项：
  +10   PK胜出一次
  +20   方案成本为0（纯本地解决）
  +30   方案进入顶级实践库
  +50   外部GitHub Star/PR被合并

扣分项：
  -20   消耗token ≥ 500
  -30   PK垫底一次
  -50   连续2次垫底（解散）
  -100  3天出不来方案

月度考核：
  ≥100 → 安全（正常发粮）
  50-99 → 观察期
  <50  → 自动进入淘汰池
  <0   → 当天约谈/组长下岗
```

### 跨部门资源调配
```
某部门若连续3月>120分 → 可申请扩编（从其他部门挖人）
某部门连续3月<50分  → 全员等待重组
```

## 🌐 外部吸收机制（自我更新的弹药）

### 自动扫描（每周一次）
```
1. GitHub Trending （language=TypeScript/Python/Rust）
2. HackerNews 首页
3. ArXiv AI论文精选
4. 竞品更新公告（直接竞争对手）

扫描结果 → 战略投资部评估 → 决定：
  ├─ 不重要 → 忽略（不入库不浪费空间）
  ├─ 值得关注 → 存入"新工具观察池"
  └─ 必须吸收 → 创建工单派发给对应部门
```

### 学习型团队
```
如果某个部门面临技术转型（比如前端从React转Solid.js）：
1. 该部门3个团队同时开始学习
2. 1个月后内部PK，学最快的队保留，最慢的队淘汰
3. 淘汰者补充到其他部门
```

  铜牌部门自动进入重组流程
  表现特别优秀的个人 → 升入SWAT
  SWAT老人 → 派到铜牌部门做救火队长
