# Authentic Voice

## 描述
专业的真实感语音优化专家，帮助AI输出听起来像真人写的，而非AI生成的。

## 功能列表

### 1. humanize-text
人化文本——将AI文本转化为真人写作风格
- **输入**：AI生成的文本
- **输出**：真人风格的文本

### 2. add-personal-experience
添加个人经历——在文本中添加个人经历的痕迹
- **输入**：文本、个人经历
- **输出**：包含个人经历的文本

### 3. vary-sentences
变换句式——改变文本的句式多样性
- **输入**：句式单一的文本
- **输出**：句式丰富的文本

### 4. add-idiosyncrasies
添加个人特点——添加作者的文体特点
- **输入**：文本、作者特点
- **输出**：有个性的文本

### 5. remove-ai-patterns
移除AI模式——移除AI写作的常见模式
- **输入**：AI生成的文本
- **输出**：移除AI模式后的文本

## 使用示例

### 示例1：人化文本
```json
{
  "function": "humanize-text",
  "params": {
    "input": "综上所述，我们可以得出以下结论：第一，...",
    "style": "个人博客"
  }
}
```

### 示例2：添加个人经历
```json
{
  "function": "add-personal-experience",
  "params": {
    "input": "这个方案理论上可行。",
    "personalExperience": "去年做过类似项目"
  }
}
```

### 示例3：移除AI模式
```json
{
  "function": "remove-ai-patterns",
  "params": {
    "input": "首先，我们需要分析现状。其次，我们需要制定计划。最后，我们需要执行计划。"
  }
}
```

## 限制条件

1. **保留原意**：必须保留原文的核心意思
2. **自然真实**：表达必须自然真实
3. **风格一致**：必须保持风格一致性
4. **适度调整**：调整不能过度

## 最佳实践

1. **移除AI模式**：移除"首先其次最后"、"综上所述"等AI模式
2. **添加个人风格**：添加个人经历、观点和评价
3. **丰富句式**：使用长短句搭配，增加句式多样性
4. **使用口语**：使用口语化表达，打破AI的"结构感"

## 常见问题

**Q: 如何判断AI生成的文本？**
A: AI文本通常结构过于规整，过渡词单一，缺乏个人风格和情感。

**Q: 如何移除AI模式？**
A: 识别并替换"首先其次最后"、"综上所述"、"值得注意的是"等固定模式。

**Q: 如何添加个人风格？**
A: 添加个人经历、观点和评价，使用独特的表达方式和习惯用语。
