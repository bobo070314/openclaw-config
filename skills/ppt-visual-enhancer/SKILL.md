# PPT Visual Enhancer

## 描述
专业的PPT视觉增强专家，帮助用户将文字内容转化为视觉化表达，提升PPT的视觉冲击力。

## 功能列表

### 1. text-to-image
文本转图片
- **输入**：文字内容、风格要求
- **输出**：生成的图片（或图片URL）

### 2. data-viz-creation
数据可视化
- **输入**：数据表格、图表类型
- **输出**：可视化图表（或图表URL）

### 3. infographic-design
信息图设计
- **输入**：复杂信息、设计风格
- **输出**：信息图（或信息图URL）

### 4. image-enhancement
图片增强
- **输入**：原始图片
- **输出**：增强后的图片

### 5. visual-consistency
视觉一致性
- **输入**：多页PPT的图片
- **输出**：视觉一致性检查结果

## 使用示例

### 示例1：文本转图片
```json
{
  "function": "text-to-image",
  "params": {
    "text": "2026年Q1季度业绩增长50%",
    "style": "商务风格"
  }
}
```

### 示例2：数据可视化
```json
{
  "function": "data-viz-creation",
  "params": {
    "data": [
      {"month": "1月", "value": 100},
      {"month": "2月", "value": 150},
      {"month": "3月", "value": 200}
    ],
    "chartType": "line"
  }
}
```

### 示例3：信息图设计
```json
{
  "function": "infographic-design",
  "params": {
    "content": "产品使用流程：1.注册→2.登录→3.使用→4.反馈",
    "style": "简洁现代"
  }
}
```

## 限制条件

1. **版权合规**：确保图片版权合规
2. **质量要求**：输出图片分辨率不低于1920x1080
3. **风格统一**：确保视觉风格与PPT整体风格一致
4. **内容适配**：确保视觉内容准确传达信息

## 最佳实践

1. **数据可视化**：数据用图表展示，趋势用折线图，占比用饼图，对比用柱状图
2. **信息图设计**：复杂流程用信息图，步骤清晰，逻辑明确
3. **图片增强**：增强图片亮度、对比度、清晰度，保持原图风格
4. **视觉一致性**：统一图片风格、尺寸、边框、阴影等

## 常见问题

**Q: 如何选择图表类型？**
A: 趋势用折线图，占比用饼图，对比用柱状图，排名用条形图。

**Q: 如何确保图片版权合规？**
A: 使用无版权图片库（Unsplash、Pexels、Pixabay），或自己拍摄/生成。

**Q: 如何保持视觉一致性？**
A: 统一图片尺寸、风格、滤镜、边框、阴影等，确保多页PPT图片风格一致。
