Generate GitHub Actions workflow YAML from natural language descriptions. Supports CI/CD pipelines, scheduled tasks, and deployment workflows.

```bash
python github-actions-generator/run.py --help
python github-actions-generator/run.py --json
python github-actions-generator/run.py --dry-run
```
