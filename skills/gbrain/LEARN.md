# 🔄 自主学习循环 — gbrain Auto-Evolve

> gbrain 的自主学习模块。定期扫描知识缺口→检索全球信息→提取精华→存入知识库。

## 能力

1. **知识缺口感知** — 发现用户提问中命中率<0.3 的未知概念
2. **自动检索学习** — 搜索 GitHub / 技术文档 / 论文
3. **结构化存入** — 提取要点存为知识库文档
4. **技能发现** — 遇到新工具/库/框架→自动查找 SKILL.md 模板
5. **反馈闭环** — 检索过的知识在后续对话中验证是否被使用

## 入口

```bash
node lib/learn.js [--query "概念名"] [--auto]
```

## 配置

- 自动运行：通过 cron 定时触发（默认每天检查一次）
- 知识缺口阈值：搜索命中 < 0.3 触发学习
- 禁用查询：避免浪费 token 的领域
