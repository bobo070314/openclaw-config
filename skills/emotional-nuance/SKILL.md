# Emotional Nuance

## 描述
专业的情感细化专家，帮助AI输出具备丰富的情感层次和共鸣力。

## 功能列表

### 1. detect-emotion
检测情感——分析文本中的情感倾向
- **输入**：文本
- **输出**：情感分析结果

### 2. add-warmth
增加温暖感——在文本中添加温暖和关怀
- **输入**：文本、温暖程度
- **输出**：添加温暖感后的文本

### 3. add-empathy
增加同理心——在文本中体现同理心
- **输入**：文本、目标受众情绪
- **输出**：添加同理心后的文本

### 4. adjust-positivity
调整积极度——提高或降低文本的积极程度
- **输入**：文本、目标积极度
- **输出**：调整后的文本

### 5. create-emotional-arc
创建情感曲线——为长文本设计情感起伏
- **输入**：文本、目标情感曲线
- **输出**：情感曲线优化后的文本

## 使用示例

### 示例1：检测情感
```json
{
  "function": "detect-emotion",
  "params": {
    "text": "我们很遗憾地通知您，您的申请未通过。"
  }
}
```

### 示例2：增加温暖感
```json
{
  "function": "add-warmth",
  "params": {
    "input": "提交您的申请之后，我们会在5个工作日内回复。",
    "warmthLevel": "高"
  }
}
```

### 示例3：增加同理心
```json
{
  "function": "add-empathy",
  "params": {
    "input": "您的订单出了问题。",
    "targetEmotion": "沮丧"
  }
}
```

1. **真实表达**：情感表达必须真实，不虚假
2. **场景适配**：情感表达必须适配场景
3. **受众适配**：情感表达必须考虑受众接受度
4. **适度表达**：情感表达不能过度

## 常见问题

**Q: 如何增加温暖感？**
A: 使用温暖词汇，添加关怀语句，表达理解和支持。

**Q: 如何体现同理心？**
A: 先理解对方情绪，再表达理解和共情。

**Q: 如何设计情感曲线？**
A: 从中性开始，逐渐提升到高潮，最后平稳结束。
