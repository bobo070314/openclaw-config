# PPT Design Aesthetic

## 描述
专业的PPT设计美学专家，帮助用户创建视觉美观、风格统一的演示文稿。

## 功能列表

### 1. suggest-color-scheme
建议配色方案
- **输入**：主题、品牌色、受众偏好
- **输出**：推荐配色方案（主色、辅色、强调色、背景色）

### 2. select-font-pair
选择字体组合
- **输入**：演示风格、可读性要求
- **输出**：推荐字体组合（标题字体、正文字体）

### 3. layout-optimization
优化页面布局
- **输入**：页面内容、目标效果
- **输出**：布局建议（网格系统、留白、对齐）

### 4. consistency-check
一致性检查
- **输入**：多页PPT
- **输出**：一致性检查结果（字体、颜色、风格）

### 5. style-transfer
风格迁移
- **输入**：源PPT风格、目标风格
- **输出**：风格迁移建议

## 使用示例

### 示例1：建议配色
```json
{
  "function": "suggest-color-scheme",
  "params": {
    "topic": "2026年产品发布会",
    "brandColor": "#0056b3",
    "audience": "企业客户"
  }
}
```

### 示例2：选择字体
```json
{
  "function": "select-font-pair",
  "params": {
    "style": "商务正式",
    "readability": "高"
  }
}
```

### 示例3：布局优化
```json
{
  "function": "layout-optimization",
  "params": {
    "content": "标题+正文+图片+数据",
    "effect": "突出重点"
  }
}
```

## 限制条件

1. **品牌一致性**：必须考虑品牌色和品牌规范
2. **可读性优先**：确保文字清晰可读
3. **风格统一**：确保多页PPT风格一致
4. **受众适配**：根据受众调整设计风格

## 最佳实践

1. **配色原则**：主色不超过3种，辅色不超过2种，强调色不超过1种
2. **字体原则**：标题和正文字体差异明显，同一文档字体不超过2种
3. **留白原则**：留白占比不低于30%，确保页面呼吸感
4. **对齐原则**：所有元素严格对齐，确保视觉整洁

## 常见问题

**Q: 如何选择配色方案？**
A: 根据主题和受众选择配色，商务主题用蓝/灰/白，科技主题用蓝/紫/白，创意主题用多彩配色。

**Q: 如何确保字体一致性？**
A: 使用相同的字体组合，标题统一用一种字体，正文统一用另一种字体。

**Q: 如何优化页面布局？**
A: 使用网格系统，确保元素对齐，合理留白，突出重点内容。
