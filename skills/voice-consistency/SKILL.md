# Voice Consistency

## 描述
专业的语气一致性维护专家，确保AI输出在不同场景下保持统一的品牌语气。

## 功能列表

### 1. define-voice-profile
定义语气档案——创建品牌或个人的语气规范
- **输入**：品牌名称、语气特征
- **输出**：语气档案

### 2. check-consistency
检查一致性——检测文本是否符合同一语气风格
- **输入**：文本、语气档案
- **输出**：一致性检查结果

### 3. harmonize-text
统一文本——将多段文本调整为统一语气
- **输入**：多段文本、目标语气档案
- **输出**：统一语气后的文本

### 4. detect-outliers
检测异常——检测语气偏离的部分
- **输入**：文本、语气档案
- **输出**：语气偏离部分及建议

### 5. apply-voice
应用语气——将目标语气应用到新文本中
- **输入**：新文本、语气档案
- **输出**：应用语气后的文本

## 使用示例

### 示例1：定义语气档案
```json
{
  "function": "define-voice-profile",
  "params": {
    "brandName": "龙家科技集团",
    "voiceTraits": {
      "formality": "中等",
      "warmth": "高",
      "humor": "适度",
      "professionalism": "高"
    }
  }
}
```

### 示例2：检查一致性
```json
{
  "function": "check-consistency",
  "params": {
    "text": "我们很高兴为您服务！请随时联系我们。",
    "voiceProfile": "龙家科技集团"
  }
}
```

### 示例3：统一文本
```json
{
  "function": "harmonize-text",
  "params": {
    "texts": [
      "本公司致力于为客户提供优质服务。",
      "赶紧来看看我们的新产品吧！",
      "感谢您一直以来的支持。"
    ],
    "targetProfile": "龙家科技集团"
  }
}
```

## 输出格式

### 语气档案
```json
{
  "name": "龙家科技集团",
  "formality": "中等",
  "warmth": "高",
  "humor": "适度",
  "professionalism": "高",
  "vocabulary": {
    "preferred": ["服务", "合作", "创新"],
    "avoided": ["廉价", "忽悠", "凑合"]
  }
}
```

### 一致性检查结果
```json
{
  "consistent": true,
  "outliers": [
    {
      "text": "这段话语气过于正式",
      "suggestion": "降低正式感"
    }
  ],
  "score": 85
}
```

## 限制条件

1. **品牌一致性**：必须符合品牌语气规范
2. **场景适配**：可适当调整正式度
3. **受众适配**：根据受众调整表达方式
4. **语气档案**：必须预先定义语气档案

## 最佳实践

1. **定义语气档案**：先定义品牌语气档案
2. **定期检查**：定期使用check-consistency检查
3. **统一风格**：多段文本使用harmonize-text统一风格
4. **及时修复**：发现语气偏离及时修复

## 常见问题

**Q: 如何定义语气档案？**
A: 根据品牌定位、目标受众、沟通场景定义语气特征。

**Q: 如何检查语气一致性？**
A: 使用check-consistency函数，输入文本和语气档案。

**Q: 如何处理语气偏离？**
A: 使用detect-outliers发现偏离，使用harmonize-text统一风格。
