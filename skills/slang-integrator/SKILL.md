# Slang Integrator

## 描述
专业的网络用语整合专家，帮助用户适当使用网络流行语和俚语。

## 功能列表

### 1. detect-slang
检测网络用语——分析文本中的网络用语
- **输入**：文本
- **输出**：网络用语分析结果

### 2. suggest-slang
建议网络用语——根据语境推荐合适的网络用语
- **输入**：文本、风格要求
- **输出**：网络用语建议

### 3. integrate-slang
整合网络用语——将网络用语融入文本
- **输入**：文本、网络用语列表
- **输出**：整合后的文本

### 4. check-appropriateness
检查适切性——检查网络用语是否适合当前场景
- **输入**：网络用语、场景
- **输出**：适切性检查结果

### 5. update-slang-database
更新网络用语库——添加新的网络用语到库中
- **输入**：新网络用语、解释、示例
- **输出**：更新结果

## 使用示例

### 示例1：检测网络用语
```json
{
  "function": "detect-slang",
  "params": {
    "text": "这个方案真的很牛，YYDS！"
  }
}
```

### 示例2：建议网络用语
```json
{
  "function": "suggest-slang",
  "params": {
    "text": "这个方案非常好。",
    "style": "年轻化"
  }
}
```

### 示例3：检查适切性
```json
{
  "function": "check-appropriateness",
  "params": {
    "slang": "YYDS",
    "scenario": "正式商务会议"
  }
}
```

## 限制条件

1. **场景适配**：网络用语必须适配使用场景
2. **频率控制**：网络用语使用频率不超过10%
3. **时效性**：只使用当前流行的网络用语
4. **文化适配**：要考虑目标受众的文化背景

## 最佳实践

1. **年轻化营销**：使用年轻人的网络用语
2. **正式场合**：避免使用网络用语
3. **社交媒体**：适度使用网络用语
4. **品牌传播**：使用与品牌调性一致的网络用语

## 常见问题

**Q: 如何使用网络用语？**
A: 根据场景和目标受众选择，年轻化场景适度使用，正式场景避免使用。

**Q: 如何检查网络用语是否过时？**
A: 定期更新网络用语库，使用update-slang-database添加最新词。

**Q: 如何处理网络用语滥用？**
A: 使用check-appropriateness检查每个网络用语的适切性，不合适的及时替换。
