### 行程规划助手
```python
def plan_trip(city, days, budget):
    """
    简易行程规划
    
    city: 城市名
    days: 天数
    budget: 预算（元/人，不含大交通）
    """
    cities_db = {
        "成都": {
            "3天": [
                "Day1: 宽窄巷子→锦里→武侯祠→九眼桥夜景",
                "Day2: 大熊猫基地→文殊院→人民公园(鹤鸣茶社)",
                "Day3: 青城山(前山)/都江堰(一日游)"
            ],
            "4天": [
                "Day1: 市区游玩（同上）",
                "Day2: 大熊猫基地+东郊记忆+玉林路",
                "Day3: 青城山+都江堰",
                "Day4: 乐山大佛(高铁1h)/三星堆(高铁40min)"
            ],
            "日均消费": 500-800,
            "美食推荐": ["火锅(小龙坎/蜀大侠)", "串串(冒椒火辣)", "兔头(双流老妈)", "蛋烘糕"],
            "避坑": "宽窄巷子和锦里吃东西贵，去本地人推荐的小巷"
        },
        "西安": {
            "3天": [
                "Day1: 兵马俑(半天)→华清池→回民街",
                "Day2: 城墙骑行→钟鼓楼→大雁塔→大唐不夜城",
                "Day3: 陕西历史博物馆(提前预约)→西安博物院"
            ],
            "日均消费": 400-600,
            "美食推荐": ["肉夹馍(子午路张记)", "羊肉泡馍(老孙家)", "凉皮(魏家)"],
            "避坑": "回民街更建议吃洒金桥，出租车坑外地人用滴滴"
        }
    }
    
    if city not in cities_db:
        return f"暂未收录{city}的攻略"
    
    info = cities_db[city]
    day_key = f"{days}天"
    itinerary = info.get(day_key, [])
    daily_cost = info['budget_per_day']
    
    return {
        "itinerary": itinerary,
        "estimated_cost": daily_cost * days,
        "food_tips": info['food_recommendations'],
        "pitfalls": info['pitfalls']
    }
```

## 四、住宿省钱技巧
- **提前30天订**比提前7天便宜20-40%
- **周二周三订**比周五周六便宜30%
- **连住3晚以上**直接问前台谈（比平台便宜）
- **学生认证/会员**：携程钻石/飞猪F2+
- **新用户优惠**：美团民宿/小猪民宿/途家首单
- **避开节假日**：春节/国庆/五一价格翻2-3倍
- **工作日捡漏**：周中很多民宿半价
