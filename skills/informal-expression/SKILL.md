# Informal Expression

## 描述
专业的非正式表达专家，帮助用户将正式文本转化为自然的口语化表达。

## 功能列表

### 1. make-informal
使非正式——将正式文本转化为非正式表达
- **输入**：正式文本
- **输出**：非正式文本

### 2. use-colloquialisms
使用口语——在文本中添加口语化表达
- **输入**：需要添加口语的文本
- **输出**：包含口语的文本

### 3. shorten-phrases
缩短短语——将长短语精简为短短语
- **输入**：长短语
- **输出**：短短语

### 4. drop-formal-words
删除正式词汇——删除文本中的正式词汇
- **输入**：包含正式词汇的文本
- **输出**：删除正式词汇的文本

### 5. use-simple-sentences
使用简单句——将复杂句转化为简单句
- **输入**：复杂句
- **输出**：简单句

## 使用示例

### 示例1：使非正式
```json
{
  "function": "make-informal",
  "params": {
    "input": "兹定于下周一上午召开会议，请各位准时出席。",
    "level": "适度"
  }
}
```

### 示例2：使用口语
```json
{
  "function": "use-colloquialisms",
  "params": {
    "input": "我们需要尽快完成这项工作。",
    "colloquialisms": ["赶紧", "快点", "火速"]
  }
}
```

### 示例3：缩短短语
```json
{
  "function": "shorten-phrases",
  "params": {
    "input": "我们需要对现状进行深入分析",
    "shortened": "我们需要分析现状"
  }
}
```

## 输出格式

## 限制条件

1. **保留原意**：必须保留原文的核心意思
2. **语气自然**：非正式表达必须自然，不生硬
3. **符合场景**：必须符合非正式场景
4. **适度非正式**：非正式不能过度，保留必要的正式感

## 最佳实践

1. **使用简单词汇**：用简单的词汇代替复杂的词汇
2. **使用短句**：用短句代替长句
3. **使用口语词**：用"呢"、"啊"、"吧"等口语词
4. **删除正式词**：删除"兹定于"、"敬请"、"特此"等正式词汇

## 常见问题

**Q: 如何使文本非正式化？**
A: 使用简单词汇，使用短句，使用口语词，删除正式词汇。

**Q: 如何使用口语？**
A: 根据场景选择合适的口语词，如"赶紧"、"快点"、"火速"等。

**Q: 如何缩短短语？**
A: 删除不必要的修饰词，保留核心意思，如"深入分析"→"分析"。
