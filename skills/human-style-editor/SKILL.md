# Human Style Editor

## 描述
专业的AI输出风格编辑器，帮助用户将AI生成的文本转化为更自然、更人性化的表达。

## 功能列表

### 1. naturalize-phrasing
自然化措辞
- **输入**：AI生成的文本
- **输出**：更自然的表达

### 2. remove-cliches
移除陈词滥调
- **输入**：包含陈词滥调的文本
- **输出**：去除了陈词滥调的表达

### 3. adjust-tone
调整语气
- **输入**：目标语气（正式/随意/友好）
- **输出**：调整后的文本

### 4. fix-repetitions
修复重复
- **输入**：包含重复的文本
- **输出**：去除了重复的表达

### 5. smoothen-flow
平滑流程
- **输入**：逻辑不连贯的文本
- **输出**：流程更连贯的文本

## 使用示例

### 示例1：自然化措辞
```json
{
  "function": "naturalize-phrasing",
  "params": {
    "input": "为了达到这一目标，我们必须采取积极的措施。首先，我们需要分析现状。其次，我们需要制定计划。最后，我们需要执行计划。",
    "targetTone": "自然"
  }
}
```

### 示例2：移除陈词滥调
```json
{
  "function": "remove-cliches",
  "params": {
    "input": "这是一个至关重要的时刻。我们需要抓住这个机遇。这是一个千载难逢的机会。"
  }
}
```

### 示例3：调整语气
```json
{
  "function": "adjust-tone",
  "params": {
    "input": "您需要尽快完成这项工作。这是必须的。",
    "targetTone": "友好"
  }
}
```

## 输出格式

## 限制条件

1. **保留原意**：必须保留原文的核心意思
2. **自然流畅**：表达必须自然流畅，不生硬
3. **符合语境**：必须符合使用场景和语境
4. **适度修改**：只修改必要的部分，不过度改动

## 最佳实践

1. **逐句检查**：逐句检查，确保每句都自然
2. **替换词汇**：用更具体的词汇替换笼统的词汇
3. **调整句式**：用更自然的句式替换生硬的句式
4. **优化过渡**：用更自然的过渡词连接句子

## 常见问题

**Q: 如何判断AI生成的文本是否自然？**
A: 朗读出来，看是否流畅；看是否像人说话；看是否有太多套路化表达。

**Q: 如何调整语气？**
A: 根据目标受众和场景选择语气，正式场合用正式语气，朋友之间用随意语气。

**Q: 如何修复重复？**
A: 找出重复的词汇或句式，用同义词或不同的表达方式替换。
