# Conversational Tone

## 描述
专业的对话语气调整专家，帮助用户将正式文本转化为对话式表达，让AI输出更有人情味。

## 功能列表

### 1. make-conversational
使对话化——将正式文本转化为对话式表达
- **输入**：正式文本
- **输出**：对话式文本

### 2. add-personality
添加个性——根据目标个性调整文本风格
- **输入**：目标个性（友好/幽默/专业）
- **输出**：有个性的文本

### 3. reduce-formalism
减少正式感——降低文本的正式程度
- **输入**：过于正式的文本
- **输出**：不那么正式的文本

### 4. add-questions
添加提问——在陈述性文本中添加提问
- **输入**：陈述性文本
- **输出**：包含提问的文本

### 5. use-contractions
使用缩写——将正式表达缩写为口语表达
- **输入**：不使用缩写的文本
- **输出**：使用缩写的文本

## 使用示例

### 示例1：使对话化
```json
{
  "function": "make-conversational",
  "params": {
    "input": "您需要尽快完成这项工作，以便我们能够按时交付。",
    "targetTone": "友好"
  }
}
```

### 示例2：添加个性
```json
{
  "function": "add-personality",
  "params": {
    "input": "我们需要完成这项工作。",
    "targetTone": "幽默"
  }
}
```

### 示例3：减少正式感
```json
{
  "function": "reduce-formalism",
  "params": {
    "input": "兹定于下周一上午召开会议，请各位准时出席。",
    "level": "适度"
  }
}
```

## 限制条件

1. **保留原意**：必须保留原文的核心意思
2. **语气自然**：对话必须自然，不生硬
3. **符合场景**：必须符合对话场景
4. **适度调整**：调整不能过度，保留必要的正式感

## 最佳实践

1. **使用第二人称**：用"你"代替"您"
2. **使用简单词汇**：用简单的词汇代替复杂的词汇
3. **使用口语表达**：用口语表达代替书面语表达
4. **添加口语词**：添加"呢"、"啊"、"吧"等口语词

## 常见问题

**Q: 如何使正式文本对话化？**
A: 使用"你"代替"您"，使用简单词汇，使用口语表达，添加口语词。

**Q: 如何添加个性？**
A: 根据目标个性选择表达方式，幽默用轻松的表达，专业用严谨的表达。

**Q: 如何减少正式感？**
A: 使用"我们"代替"本公司"，使用"尽快"代替"立刻"，使用"完成"代替"执行"。
