# PPT Structure Optimizer

## 描述
专业的PPT结构优化专家，帮助用户快速构建逻辑清晰、层次分明的演示文稿结构。

## 功能列表

### 1. generate-ppt-outline
生成PPT大纲结构
- **输入**：主题、目标受众、演示时长
- **输出**：结构化大纲（章节、要点、时长）

### 2. improve-structure
优化现有PPT结构
- **输入**：现有PPT内容
- **输出**：优化后的结构建议

### 3. validate-structure
验证PPT结构逻辑
- **输入**：PPT结构
- **输出**：逻辑检查结果（通过/不通过）+ 修改建议

### 4. create-sequence
创建逻辑顺序
- **输入**：多个要点
- **输出**：最优逻辑顺序

### 5. identify-gaps
识别结构缺失
- **输入**：现有PPT结构
- **输出**：缺失内容提示

## 使用示例

### 示例1：生成大纲
```json
{
  "function": "generate-ppt-outline",
  "params": {
    "topic": "2026年Q1季度总结报告",
    "audience": "公司管理层",
    "duration": "30分钟"
  }
}
```

### 示例2：优化结构
```json
{
  "function": "improve-structure",
  "params": {
    "existingContent": "现有PPT内容...",
    "goal": "提高逻辑性和说服力"
  }
}
```

### 示例3：验证结构
```json
{
  "function": "validate-structure",
  "params": {
    "structure": {
      "title": "季度总结",
      "sections": [
        {"name": "引言", "points": ["背景", "目标"]},
        {"name": "数据", "points": ["销售数据", "用户增长"]},
        {"name": "分析", "points": ["SWOT分析"]}
      ]
    }
  }
}
```


## 限制条件

1. **结构化输出**：必须使用JSON格式
2. **逻辑验证**：必须检查逻辑一致性
3. **时长控制**：必须符合用户指定时长
4. **受众适配**：必须考虑目标受众特点

## 最佳实践

1. **先验证后生成**：验证现有结构再生成新结构
2. **逻辑先行**：确保逻辑顺序合理
3. **层次清晰**：确保章节和要点层次分明
4. **目标导向**：根据演示目标调整结构

## 常见问题

**Q: 如何处理复杂的主题？**
A: 将复杂主题拆分为多个章节，每章聚焦一个子主题。

**Q: 如何确保结构逻辑？**
A: 使用"引言-主体-结论"的经典结构，确保每个章节有明确的主题和支撑要点。

**Q: 如何优化现有PPT结构？**
A: 先识别结构问题，再提出改进建议，最后给出优化后的完整结构。
