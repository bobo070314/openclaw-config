## 三、OBD故障码查询

### OBD-II标准故障码
```python
OBD_CODES = {
    # 动力系统 P01xx-P03xx
    "P0101": {"desc": "空气流量计故障", "severity": "中", "fix": "清洗或更换"},
    "P0171": {"desc": "系统过稀（空燃比）", "severity": "中", "fix": "检查真空泄漏/氧传感器"},
    "P0300": {"desc": "随机/多缸失火", "severity": "高", "fix": "检查火花塞/点火线圈"},
    "P0301": {"desc": "1缸失火", "severity": "高", "fix": "换点火线圈或火花塞"},
    "P0420": {"desc": "三元催化效率低", "severity": "中", "fix": "清洗或更换三元催化"},
    
    # 底盘 Cxxxx
    "C0035": {"desc": "左前轮速传感器", "severity": "高", "fix": "清洗或更换"},
    "C0040": {"desc": "右前轮速传感器", "severity": "高", "fix": "清洗或更换"},
    
    # 车身 Bxxxx
    "B1000": {"desc": "安全气囊系统", "severity": "高", "fix": "4S店检测"}
}

def diagnose_code(code):
    """查询OBD故障码"""
    code = code.upper()
    if code in OBD_CODES:
        info = OBD_CODES[code]
        return f"故障码: {code}\n描述: {info['desc']}\n严重程度: {info['severity']}\n建议: {info['fix']}"
    return f"未知故障码: {code}，建议查手册或4S店"
```

### 读取OBD数据
```python
# 需要 OBD-II 蓝牙适配器
import obd  # pip install obd

def read_car_data():
    connection = obd.OBD()  # 自动连接蓝牙
    if not connection.is_connected():
        return "OBD未连接"
    
    data = {
        "RPM": connection.query(obd.commands.RPM),
        "车速": connection.query(obd.commands.SPEED),
        "冷却水温": connection.query(obd.commands.COOLANT_TEMP),
        "进气温度": connection.query(obd.commands.INTAKE_TEMP),
        "燃油量": connection.query(obd.commands.FUEL_LEVEL),
        "电池电压": connection.query(obd.commands.CONTROL_MODULE_VOLTAGE),
        "故障码": connection.query(obd.commands.GET_DTC)
    }
    return data
```

## 四、DIY保养教程

### 换机油（适合DIY）
```python
DIY_OIL_CHANGE = """
步骤：
1. 热车2分钟（让机油流动）
2. 准备：新机油/机滤/扳手/接油盆/手套
3. 拧开放油螺丝 → 放旧油
4. 换新机滤（先涂油密封圈）
5. 拧紧放油螺丝
6. 加新机油（分2-3次加，检查油尺）
7. 启动1分钟 → 熄火检查油位

注意：
- 废油不可倒下水道，送维修店回收
- 机滤不要拧太紧（力矩25N·m）
- 放油螺丝拧紧力矩30-40N·m
"""
```
