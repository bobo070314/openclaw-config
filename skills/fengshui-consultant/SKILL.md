## 住宅风水

### 大门风水
```
开天门（入户门）：
- 大小适中（过大漏财，过小纳气不足）
- 门前开阔，明堂聚气
- 不对楼梯/电梯/厕所/厨房
- 不对邻居大门（对门煞）
- 大门前不放鞋柜（纳气受阻）

进门三见三不见：
✓ 见喜庆（玄关装饰/画） ✓ 见绿色（植物） ✓ 见明亮（光线）
✗ 见灶台（火冲门） ✗ 见厕所（秽气冲门） ✗ 见镜子（财气反射）
```

### 卧室风水
```
床位：
- 床头靠实墙（有靠山）
- 不对门（冲煞）
- 不对窗（漏气）
- 不对镜子（夜半惊心）
- 上方无横梁/吊灯

颜色：
- 暖色调（米色/浅黄）👉 利于感情
- 冷色调（灰/蓝）👉 利于独处
- 忌大红大紫（刺激难眠）
```

### 厨房风水
```
炉灶不背门（无靠）
炉灶不对水槽（水火冲）
冰箱不对炉灶（冷热冲）
镜子不对炉灶（双重火）
忌开放式厨房（藏污纳气）
```

### 厕所风水
```
门常关、盖常合
保持干燥通风
不宜在房屋中心（中宫忌秽）
不住人（影响健康）
不宜对床/对门/对灶
```

## 常见问题

**Q: 买了二手房需要重新看风水吗？**
A: 建议。前任的运势会影响宅基气场，特别是大病/破产/离婚的房子。

**Q: 租房需要看风水吗？**
A: 短期（<6月）不用，长期（>1年）建议简单布局（床位/办公位）。

**Q: 公寓楼风水怎么看？**
A: 楼栋位置>楼层>朝向>户型和内部布局。6-10层中高层最佳。
