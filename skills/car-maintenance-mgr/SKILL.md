# 汽车保养记录与提醒

> 汽车保养记录与提醒 - 保养日程管理、费用追踪、到期自动提醒

## 前置依赖

```bash
pip install pandas openpyxl
```

## 核心能力

### 能力1：询问车型和当前里程数

用 `web_search` 搜索车型的官方保养周期表，用 `automation_update` 创建保养到期提醒定时任务。

### 能力2：根据厂家建议生成保养日程表（write_to_file）

用 `write_to_file` 生成文件。

### 能力3：记录每次保养项目和费用

用 `web_search` 搜索车型的官方保养周期表，用 `automation_update` 创建保养到期提醒定时任务。

### 能力4：用 automation_update 设置保养到期提醒

用 `automation_update` 创建定时任务。

### 能力5：生成年度保养费用统计

用 `write_to_file` 生成文件。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 车辆品牌和型号
- 当前里程数
- 上次保养日期和内容
- 是否有异常症状需要诊断？

### 步骤 2：检索外部信息

执行以下搜索获取真实数据：

```
web_search("[车型] 保养手册 周期表")
web_search("[车型] [里程数]公里 保养项目")
web_search("[车型] maintenance schedule")
```

确保获取到以下资源：
- 车型保养手册参考
- 保养项目价格参考

### 步骤 3：运行脚本处理数据

```bash
python3 scripts/car_maintenance_mgr_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 4：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **保养日程表**
- **费用记录表**
- **年度统计报告**

输出格式要求：保养日程 + 费用记录 + 定时提醒确认

### 步骤 5：设置定时任务

用 `automation_update` 创建定时任务：
```
automation_update:
  name="汽车保养记录与提醒"
  rrule=FREQ=DAILY;BYHOUR=9;BYMINUTE=0
  prompt="执行汽车保养记录与提醒skill的定时任务"
```

### 步骤 6：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议
4. 定时任务创建确认
