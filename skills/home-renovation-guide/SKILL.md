# home-renovation-guide — 装修全流程指南

> 装修全流程管理 — 预算/设计/施工/材料/验收/避坑

## 一、装修模式选择

```python
RENOVATION_MODES = {
    "清包": {
        "适合": "懂装修/有时间的人",
        "自己": "买所有材料",
        "施工队": "只出人工",
        "优点": "省钱（比全包省20-30%）, 所有材料自己把控",
        "缺点": "极其费时（每天盯工地）, 出了问题扯皮"
    },
    "半包": {
        "适合": "稍微懂/部分时间在的人",
        "自己": "买主材（瓷砖/地板/洁具/开关/灯具）",
        "装修公司": "辅材（水泥/沙子/电线/水管）+人工",
        "优点": "主材自己选品质, 施工有公司管",
        "缺点": "辅材坑多（便宜辅材会出问题）"
    },
    "全包": {
        "适合": "没时间/第一次装修/不怕多花钱",
        "装修公司": "包工包料（含家电可谈）",
        "优点": "省心（只需验收）, 出了问题公司全责",
        "缺点": "贵（比半包贵15-30%）, 主材选择受限"
    }
}
```

## 五、避坑指南（重点）

```python
COMMON_PITFALLS = {
    "水电": [
        "横槽不开（破坏墙体结构）",
        "强弱电分开管（间距>30cm）",
        "冰箱单独一路电（出差不关）",
        "厨房卫生间用4平方线（不是2.5）",
        "水管走顶（漏水易发现）",
        "热水管包保温棉",
        "闭水试验做48h（不是24h）"
    ],
    "泥瓦": [
        "瓷砖留缝2mm（热胀冷缩）",
        "墙地砖对缝（强迫症福音）",
        "卫生间地面做坡度（至少2%）",
        "过门石比卫生间地面高5mm",
        "贴砖前做拉毛（防止脱落）"
    ],
    "木工": [
        "吊顶转角用7字形石膏板（防开裂）",
        "轻钢龙骨>木龙骨（防变形）",
        "柜子做到顶（不积灰）",
        "窗帘盒留宽度（电动窗帘要20+cm）"
    ],
    "油漆": [
        "腻子干透再刷漆（至少干2天）",
        "底漆必须刷（防发霉/增加附着力）",
        "阴角贴角条（直线漂亮）",
        "最后一遍面漆等家具进场再刷"
    ],
    "安装": [
        "开关插座高度统一（距地30cm）",
        "插座带USB口（方便）",
        "厨房台面高度=身高/2+5（不累腰）"
    ]
}
```

## 六、验收清单

```python
INSPECTION_CHECKLIST = {
    "水电验收": [
        "打压测试(0.8MPa 30min不掉压)",
        "通电测试(每个插座都带负载)",
        "暖气打压(0.6MPa)",
        "拍照留底(日后打孔用)",
        "回路标记(电箱标签)"
    ],
    "瓦工验收": [
        "空鼓率<5%(敲击检查)",
        "平整度(2米靠尺<2mm)",
        "阴阳角方正(90°±2°)",
        "坡度试水(水流顺畅无积水)"
    ],
    "木工验收": [
        "水平度(水平仪测量)",
        "牢固度(用力摇晃)",
        "接缝处理(贴绷带/防裂)"
    ],
    "油漆验收": [
        "平整光洁无流坠",
        "颜色均匀无色差",
        "阴角直线/阳角垂直"
    ],
    "竣工验收": [
        "每个开关插座通电",
        "水龙头/马桶/地漏下水",
        "门窗开合顺畅",
        "暖气/空调开30分钟测试",
        "甲醛检测(<0.08mg/m³)"
    ]
}
```

## 七、除甲醛
```
通风（最好的方法）：装修完通风3-6个月
活性炭：200g/㎡，每月更换
空气净化器：CADR值>300m³/h
植物：绿萝/吊兰/虎皮兰（辅助）
专业除甲醛：5000-10000元
不推荐：果皮/醋/水（没用）
```
