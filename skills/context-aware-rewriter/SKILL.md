# Context-Aware Rewriter

## 描述
专业的上下文感知重写专家，能够根据不同的语境和场景重写文本，确保表达精准适配。

## 功能列表

### 1. detect-context
检测上下文——分析文本的使用场景、受众和目的
- **输入**：文本
- **输出**：上下文分析结果

### 2. adapt-to-scenario
适配场景——根据目标场景调整文本风格
- **输入**：文本、目标场景
- **输出**：适配场景后的文本

### 3. adapt-to-audience
适配受众——根据目标受众调整语言难度和风格
- **输入**：文本、目标受众
- **输出**：适配受众后的文本

### 4. adapt-to-format
适配格式——根据目标格式调整结构和长度
- **输入**：文本、目标格式
- **输出**：适配格式后的文本

### 5. rewrite-with-context
全量重写——根据完整上下文信息重写文本
- **输入**：文本、上下文信息
- **输出**：重写后的文本

## 使用示例

### 示例1：适配场景
```json
{
  "function": "adapt-to-scenario",
  "params": {
    "input": "我们需要完成这项工作。",
    "targetScenario": "紧急项目"
  }
}
```

### 示例2：适配受众
```json
{
  "function": "adapt-to-audience",
  "params": {
    "input": "这个产品性能很好。",
    "targetAudience": "技术专家"
  }
}
```

### 示例3：全量重写
```json
{
  "function": "rewrite-with-context",
  "params": {
    "input": "请提交本季度报告。",
    "context": {
      "scenario": "商务邮件",
      "audience": "上级领导",
      "urgency": "中等"
    }
  }
}
```

## 输出格式

## 限制条件

1. **保留原意**：必须保留原文的核心意思
2. **场景适配**：必须适配目标场景
3. **受众适配**：必须适配目标受众
4. **格式适配**：必须适配目标格式

## 最佳实践

1. **先分析上下文**：先使用detect-context分析上下文
2. **再适配场景**：根据场景选择合适的表达方式
3. **再适配受众**：根据受众调整语言难度和风格
4. **最后适配格式**：根据格式调整结构和长度

## 常见问题

**Q: 如何适配不同场景？**
A: 正式场景用正式语言，非正式场景用随意语言，紧急场景用短句。

**Q: 如何适配不同受众？**
A: 专家受众用专业语言，普通受众用通俗语言，客户受众用友好语言。

**Q: 如何处理复杂上下文？**
A: 先分析上下文的所有维度，再根据优先级适配最重要的维度。
