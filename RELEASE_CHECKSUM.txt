## System Requirements
- Windows 10/11 or Windows Server 2019+
- Python 3.10+ (tested on 3.14)
- PowerShell 5.1+

## Known Limitations
- OpenClaw Gateway not included in this package. Requires separate gateway setup on port 18900.
- Heartbeat check will show "unreachable" if gateway is not running — this is expected.
