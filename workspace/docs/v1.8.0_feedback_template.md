# v1.8.0 用户反馈模板

## 技术用户（张工）

```
你跑完演示包后，方便回我几个问题吗？

1. 从下载到跑通 init.ps1，用了多久？
2. 有没有遇到报错或者不清楚的文档？
3. 这套自动修复功能（S1 文件补全 / S2 配置修正 / S3 权限恢复），你觉得哪个对你最有用？
4. 有没有什么功能是你需要但没看到的？
```

## 决策者（李总）

```
您试用后，有几个小问题想确认一下：

1. 30 秒启动和零维护的体验，和您预期一致吗？
2. 有没有遇到不懂的操作步骤？
3. 这套系统如果落地到您团队，还需要我们配合什么？
4. 如果满分 10 分，您打几分？
```

## 信任敏感（刘老板）

```
您试完之后跟我说下真实感受就行：

1. 部署过程有没有遇到问题？
2. 有没有哪个环节让您觉得不够安全/不够透明？
3. 这套系统您最看重的是哪个能力？
4. 会考虑推荐给同行吗？
```
