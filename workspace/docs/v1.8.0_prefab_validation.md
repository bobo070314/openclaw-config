## 已解决风险

| 风险 | 等级 | 状态 |
|---|---|---|
| 正则匹配基于固定字符串，实战 fail_reason 变体不同 | 🟢 已解决 | 改用正则模糊匹配 `(file\|missing\|no\s+such)` / `(config\|invalid\|bad\|syntax\|parse)` / `(rbac\|permission\|access\|denied\|forbidden\|unauthorized)` |
| "access to configs denied" 双重命中 ConfigError 和 RBACViolation | 🟢 已解决 | 调整匹配优先级为 FileMissing > RBACViolation > ConfigError > Unknown |
| latest_eval.json 缺失/为空/缺字段时函数崩溃 | 🟢 已解决 | 添加空数据保护：None 返回零值，空 checks 列表返回零值，缺 checks 键返回零值 |
| S1 补全模板未预置 | 🟢 已解决 | S1_TEMPLATES 含 agent_chain.yaml + README.deliver.md |
| S2/S3 模板缺失 | 🟢 已解决 | S2 和 S3 模板均含带版本说明的 agent_chain.yaml 恢复配置；S3 额外含 default_roles |
