# A 线 D2 追打话术（优化版）

> **适用**: 张工 / 李总 / 刘老板
> **触发时间**: 首触达后 24h 未回
> **策略**: 1 句提醒 + 1 个动作（演示包运行结果快照）

---

## 张工（技术）

```
[称呼]，资料收到了。

我顺手跑了一份当前系统的运行快照，放在附件里。
pass_rate 1.0，零报错。解压后跑 `scripts/init.ps1` → `scripts/orchestrator.py` 即可复现。

对了，系统内置了自动修复引擎 —— 文件丢了自动补、配置错了自动修、权限乱了自动恢复。
跑一遍 `python scripts/auto_fixer_demo.py` 就能看到效果。

有问题随时聊。
```

## 李总（决策者）

```
[称呼]，资料发您两天了，想问下您那边看了吗？

如果有兴趣，这周安排 15 分钟我跑一遍演示，您看行不行？
```

## 刘老板（信任敏感）

```
[称呼]，之前那套系统您试过没有？

如果还没动，有需要随时问。我这边一直在，不催您。
```

---

## 不适用场景

- 对方已在 D1 回复 → 用分流话术（感兴趣/追问/观望三类），不走 D2
- 对方已明确拒绝（"不需要""没兴趣"）→ 走拒绝分支话术，尊重退场，留钩子

---

如果之后有团队在做相关的事，帮我们搭个线就好。
