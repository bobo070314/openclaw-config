# v2.0 候选技术清单（记录不实施）

## 1. quorvex_ai — AI 自愈测试框架

- **链接**: https://github.com/NihadMemmedli/quorvex_ai
- **价值**: 自然语言用例转 Playwright 自愈测试，与 auto_fixer S1/S2/S3 逻辑同构（检测→修复→验证），可作为工业端思路对比参考
- **风险**: 场景隔离（浏览器 ≠ 工业 MES），硬件故障语义（电极裂纹 / 硅料污染）不在其故障模型覆盖范围内
- **触发条件**: v2.0 扩展"测试用例自动生成"模块时评估

---

## 2. headroom (headroomlabs-ai) — MCP Token 压缩

- **链接**: https://github.com/headroomlabs-ai/headroom
- **价值**: MCP 服务器模式，工具输出/日志/文件进入 LLM 前压缩 60-95%，与当前 metamcp 架构兼容
- **风险**: 引入新依赖可能增加观测窗复杂度；压缩率在工业场景下未经验证
- **触发条件**: v2.0 对接合盛 MES 后，日志量 > 1GB/天（兜底方案，非 P0）

---

## 3. MCP 生态增长 — 17K+ 仓库（6 个月翻倍）

- **价值**: 验证 metamcp 架构押注路线正确
- **风险**: 无（仅路线信号）
- **触发条件**: 持续跟踪生态演进；若 MCP 仓库增速放缓至 < 5%/月，重新评估架构风险
